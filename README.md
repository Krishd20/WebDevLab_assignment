# Student Expense Tracker

A responsive web-based **Student Expense Tracker** built using HTML, CSS, and vanilla JavaScript. This application allows students to record, categorize, filter, and manage their daily expenses in Indian Rupees (₹) with real-time total calculation.

## Features
- **Add Expenses:** Record expense name, amount (₹), and category (`Food`, `Travel`, `Shopping`, `Education`, `Other`) dynamically without page reloads.
- **Input Validation:** Prevents empty expense names and invalid or non-positive amounts from being submitted.
- **Live Total Calculation:** Automatically calculates and updates total expenses whenever items are added, deleted, or filtered.
- **Category Filter:** Filter displayed expenses by specific categories or view all records at once.
- **Delete Functionality:** Remove individual expenses with automatic total recalculation.
- **Responsive Dark UI:** Clean, mobile-friendly interface styled with modern CSS.

## Technologies Used
- **HTML5:** Structure and form controls
- **CSS3:** Responsive layout and dark-theme styling
- **JavaScript (ES6 & DOM Manipulation):** Dynamic rendering, filtering, validation, and calculations
